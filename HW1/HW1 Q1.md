# 验证严格快于 O(n^4) 的算法

> Continuing from [寻找更快算法](chatgpt-conversation://6ad07800-5344-83ea-b6e2-54c84f4fee43): 分析用户上传的两份 PDF（作业第一题与用户原解答），深入推导并验证严格快于 O(n^4) 的准确算法，解释 α^p+α^q 的作用，尽可能查阅相关算法文献，中文详细汇报正确性与复杂度。

**可以找到严格快于 \(O(n^4)\) 的精确算法，而且确实可以直接从 \(\alpha^p+\alpha^q\) 出发判断可行性，不必先求精确最优距离。**我推导并实现验证的结果是：

- 固定最大高度 \(H\) 和 \(\alpha>1\) 时，直接求题目要求的最小候选距离，可以做到 **\(O(n^3\sqrt{\log n})\)**。

**更快方法的核心，是直接判断一个距离 \(d\) 是否可行。**

定义

\[
V_d(s,t)=
\sum_{\substack{0\le i,j<n\\0\le i+s,j+t<n}}
\mathbf 1\!\left[A_{i+s,j+t}+B_{ij}>d\right].
\]

它统计该平移下会穿透的柱对数。因此

\[
d\text{ 可行}
\iff
\exists(s,t):V_d(s,t)=0.
\]

注意这里必须用严格大于号：高度和等于 \(d\) 时只是接触，应当允许。

现在，目标变成：**一次批量求出全部平移的 \(V_d\)，避免逐个扫描。**

条件

\[
A_{uv}+B_{ij}>d
\iff
A_{uv}>d-B_{ij}
\]

属于经典的 less-than / dominance pattern matching。这类问题已有分块与卷积算法；2019 年的 *Hamming Distance Completeness* 讨论了这类匹配与二维图像模板匹配之间的联系。下面给出的算法是针对本题的具体构造，复杂度由后面的分析直接证明。[论文原文](https://drops.dagstuhl.de/storage/00lipics/lipics-vol128-cpm2019/LIPIcs.CPM.2019.14/LIPIcs.CPM.2019.14.pdf)

令 \(N=n^2\)，把 \(A\) 的全部 \(N\) 根柱子按高度排序，**保留其原始坐标**，然后每 \(b\) 根分为一组。排序只是为了分组，并没有改变框架的空间排列。

对任意一组 \(G\)，记最小、最大高度为

\[
L_G=\min_{a\in G}a,\qquad U_G=\max_{a\in G}a.
\]

对于上框架的一根高度为 \(h\) 的柱子，有三种情况：

| 条件                 | 它与组 \(G\) 内柱子的关系    |
| -------------------- | ---------------------------- |
| \(h>d-L_G\)          | 与组内每根柱子相遇都会穿透   |
| \(h\le d-U_G\)       | 与组内任何柱子相遇都不会穿透 |
| \(d-U_G<h\le d-L_G\) | 需要比较具体高度             |

第一种用一次卷积批量处理；第三种直接检查。关键是证明第三种检查的总量足够小。

**一次二维卷积，可以处理一整组柱子与全部平移。**

为组 \(G\) 构造两个 0–1 矩阵：

\[
P_G[u,v]=\mathbf 1[(u,v)\in G],
\]

\[
Q_G[i,j]=\mathbf 1[B_{ij}>d-L_G].
\]

于是

\[
C_G(s,t)=\sum_{i,j}P_G[i+s,j+t]Q_G[i,j]
\]

恰好统计：在平移 \((s,t)\) 下，该组中那些“必然穿透”的柱对数。

将 \(Q_G\) 在两个方向反转，再计算二维普通卷积，即可同时得到全部 \(C_G(s,t)\)。两个输入都是 \(n\times n\)，补零后的卷积规模为 \(O(n^2)=O(N)\)，计算时间为

\[
O(N\log N).
\]

这里用的是普通的“加法—乘法”卷积，**没有把 max-plus convolution 错当成普通 FFT 卷积**。我们先把高度比较转成了 0–1 计数。

具体地，若

\[
\widetilde Q_G[x,y]=Q_G[n-1-x,n-1-y],
\]

则

\[
(P_G*\widetilde Q_G)[n-1+s,n-1+t]=C_G(s,t).
\]

这也明确了平移方向和输出下标。

**剩余的模糊情况，总共只需 \(O(Nb)\) 次比较。**

对组 \(G\)，只有满足

\[
h\in(d-U_G,\ d-L_G]
\]

的上框架柱子需要单独检查。

由于各组是按高度连续分出来的，

\[
U_{G_r}\le L_{G_{r+1}}.
\]

因此，各组的区间

\[
(d-U_G,\ d-L_G]
\]

互不重叠，包括重复高度造成的边界情况。

所以，**每根 \(B\) 柱子至多落入一个组的模糊区间**。一旦落入，只需与该组至多 \(b\) 根柱子比较，总比较次数至多 \(Nb\)。

对于发现的一对穿透柱子 \(A_{uv},B_{ij}\)，它只影响一个平移：

\[
(s,t)=(u-i,v-j).
\]

直接把对应的 \(V_d(s,t)\) 加一即可。

这个分析避免了一个常见错误：如果每一组都对全部柱对暴力检查，就会重新退化为 \(O(n^4)\)；这里依赖的是模糊区间互不重叠。

单次判定可以写成：

```text
Feasible(d):
    V[所有合法整数平移] = 0

    对 A 的每个高度组 G：
        L = G 的最小高度
        U = G 的最大高度

        P = G 中柱子的空间位置指示矩阵
        Q = B 中高度 > d-L 的柱子的位置指示矩阵
        V += Correlation(P, Q)

        对每根满足 d-U < B[i,j] <= d-L 的柱子：
            对 G 内每根 A[u,v]：
                如果 A[u,v] + B[i,j] > d：
                    V[u-i, v-j] += 1

    若某个 V[s,t] = 0：
        返回 true 和平移 (s,t)
    否则返回 false
```

**它的正确性来自对全部柱对的精确划分。**

任取一对 \(a\in G\) 和 \(h\)：

- 若 \(h>d-L_G\)，则 \(a+h>d\)，由卷积统计。
- 若 \(h\le d-U_G\)，则 \(a+h\le d\)，不统计。
- 否则直接比较 \(a+h>d\)。

三种情况互斥且穷尽全部可能。因此每个穿透柱对恰好统计一次，没有漏计或重复计数。最终算出的就是定义中的 \(V_d(s,t)\)，所以零计数与该平移可行完全等价。

**单次判定的复杂度为 \(O(n^3\sqrt{\log n})\)。**

共有 \(O(N/b)\) 个高度组，每组进行一次 \(O(N\log N)\) 的卷积；模糊柱对比较总共 \(O(Nb)\) 次。因此

\[
T_{\mathrm{decision}}(N,b)
=
O\!\left(
N\log N+\frac{N^2\log N}{b}+Nb
\right).
\]

取

\[
b=\Theta(\sqrt{N\log N}),
\]

得到

\[
T_{\mathrm{decision}}
=O(N^{3/2}\sqrt{\log N})
=\boxed{O(n^3\sqrt{\log n})}.
\]

并且

\[
\frac{n^3\sqrt{\log n}}{n^4}
=\frac{\sqrt{\log n}}n\longrightarrow0,
\]

所以这是严格的 \(o(n^4)\)。

逐组复用卷积工作区即可，辅助空间为 \(O(N)=O(n^2)\)。如果希望分析更简单，也可以直接取 \(b=n\)，得到仍然严格优于四次方的 \(O(n^3\log n)\) 判定算法。

**现在可以解释 \(\alpha^p+\alpha^q\) 的作用了。**

令最大输入高度为 \(H\)，并取

\[
K=\left\lceil\log_\alpha(2H)\right\rceil.
\]

只需考虑有限集合

\[
\mathcal S=
\{\alpha^p+\alpha^q:0\le p,q\le K\}.
\]

理由与你原解答一致：

\[
D^*\le2H\le\alpha^K,
\]

所以 \(1+\alpha^K\) 一定可行；任何含有大于 \(K\) 的指数的候选，都大于这个已知可行值，不可能成为最小答案。

接下来，**直接对这些候选调用上面的判定算法**。可行性单调：

\[
d\text{ 可行},\ d'\ge d
\quad\Longrightarrow\quad
d'\text{ 可行}.
\]

因此，将 \(\mathcal S\) 排序去重后，可以二分找到第一个可行值，同时返回一个可行平移：

```text
生成并排序 S = {α^p + α^q : 0 <= p,q <= K}
在 S 上二分：
    用 Feasible(S[mid]) 判断是否存在可行平移
返回第一个可行候选及其平移
```

全过程不需要求出 \(D^*\)。

保留参数后的时间界为

\[
O\!\left(
n^2\log n
+K^2\log(K+2)
+\log(K+2)\,n^3\sqrt{\log n}
\right).
\]

当 \(H,\alpha\) 固定时，\(K\) 是常数，得到

\[
\boxed{O(n^3\sqrt{\log n})}.
\]

所以，你原来的直觉有一个可以严格证明的版本：

> \(\alpha^p+\alpha^q\) 将输出限制为有限候选集合，使我们可以直接做候选距离的可行性判定，省去精确最优化这一层。
